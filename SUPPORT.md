# Getting help

- **Something isn't working?** Check the [FAQ](README.md#faq) first, then [open a bug report](https://github.com/Kasra-Sartaee/econpulse/issues/new/choose). Paste the output of **Settings → About → Copy diagnostics**: it contains the version and recent errors, never your API key or personal files.
- **An idea or a question?** [Open a feature request](https://github.com/Kasra-Sartaee/econpulse/issues/new/choose), or start a thread in [Discussions](https://github.com/Kasra-Sartaee/econpulse/discussions) if it's enabled.
- **A security problem?** Please report it privately, as described in [SECURITY.md](SECURITY.md).
- **Wrong or missing calendar data?** EconPulse shows what its data source publishes. Check the event on the source's own site (the release details window links to it). If the source is right and EconPulse is wrong, that's a bug: please report it.

EconPulse is maintained by volunteers in their spare time, so replies can take a few days. Nothing in this app or its support channels is financial advice.
