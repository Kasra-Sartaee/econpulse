Features

Everything you check before a release, in one glance.

Built for traders and anyone who follows the macro calendar: quick to read, quiet until it matters, and sharp on every screen.

Floating countdown

An always-on-top widget shows the next high-impact release and today's or this week's schedule. Drag it anywhere; it remembers its monitor.

Full calendar

Calendar, Today, Upcoming, Released and Bank holidays views, with search, currency and impact filters and a live "now" line.

Actual, Forecast, Previous

Values update as they're published, with a details window for every release and a link to the original source.

Alerts that respect you

Desktop notifications 30, 15 and 5 minutes before high-impact releases and as they land. Each one optional, sound included.

Export

Save what you see to CSV for spreadsheets or ICS for your calendar app. Exports are safe to open in Excel.

English and Persian

Persian mirrors the whole layout right to left and shows Solar Hijri dates. Adding a language is a single file.

Tour

Fast, calm, and made for the desktop.

Views, filters, search, light and dark themes, and right-to-left Persian, all in a native app that starts in about a quarter of a second.

Data sources

Honest about where the numbers come from.

There's no EconPulse server. Your computer fetches the calendar directly from a source whose terms allow it, at most every 15 minutes, and backs off when a source asks it to wait.

Default

biquote

Schedule, impact, Actual, Forecast and Previous for about 50 countries. Free, no key needed.

Automatic fallback

Forex Factory weekly export

The official schedule feed: this week's releases with Forecast and Previous, but no Actual values.

Optional

FinanceCalendar.com

Data from official statistics agencies, with your own API key. Paid plans include the figures.

EconPulse isn't affiliated with any data provider. Nothing in the app is financial advice; check important figures at the source before acting on them.

Privacy & security

Your desktop, your data.

EconPulse is open source, so all of this can be checked.

  • No account, no telemetry, no analytics. The app never phones home.
  • Local only. Settings, cache and trading notes stay in your user folder.
  • HTTPS everywhere, with size limits on every response and validation of every field.
  • Verifiable downloads. Every release is built on GitHub from hash-pinned tools, with checksums, a software bill of materials and a signed build attestation.
  • Continuously checked by CodeQL, Bandit, pip-audit and OpenSSF Scorecard.

Get started

Up and running in a minute.

Download

Get EconPulse-{{VERSION}}-Windows.zip from the latest release.

Unzip and run

Open EconPulse.exe. No installer and no Python needed. SmartScreen may ask once: choose More info → Run anyway.

Make it yours

Pick currencies, alerts, theme and language in Settings. Turn on Start at login to keep it running.

# macOS, Linux, or Windows from source (Python 3.10+)
git clone https://github.com/Kasra-Sartaee/econpulse.git
cd econpulse
python -m pip install -r requirements.txt
python -m econpulse          # or --demo for sample data
